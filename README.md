# YMM4 シャッターブラー v0.2.0

実在する連続フレームをGPU上で時間方向に合成する、YukkuriMovieMaker4用の映像エフェクトです。
光学フローを使わないため、人や背景の境界が推定ミスで歪むことはありません。

## 動作環境

- ゆっくりMovieMaker4 v4.47.0.0以降（.NET 10版）
- Windows 10/11
- Direct2Dの加算合成に対応するGPU

開発時のビルド確認はYMM4 v4.56.1.0 Liteの公開APIを参照して行っています。

## インストール

配布ファイル `YMM4ShutterBlur-v0.2.0.ymme` をダブルクリックし、YMM4の案内に従ってください。
v0.1.0を導入済みの場合は、そのまま上書きインストールできます。

手動の場合は `YMM4ShutterBlur.dll` を次のフォルダーへ置き、YMM4を再起動します。

```text
YukkuriMovieMaker4\user\plugin\YMM4ShutterBlur\YMM4ShutterBlur.dll
```

映像アイテムのエフェクト一覧から「フィルター」→「シャッターブラー」を追加します。

## 設定

| 項目 | 内容 |
|---|---|
| 露光フレーム | 混ぜるサンプル数。1～8F、0.1F単位。1でブラーなし |
| サンプリング間隔 | 履歴を拾う間隔。通常は1F、`A A B B`型の重複30fps素材は2F |
| 重み | 「均等」または「線形（古いほど薄い）」 |
| 線形減衰 | 0%で均等、100%で完全な線形減衰。「線形」のときだけ使用 |
| ミックス | 100%で完全な時間平均。下げるほど現在フレーム主体。初期値70% |
| フレーム保持 | 同じ出力を何フレーム表示するか。60fps→30fps風なら2 |

### 60fps素材の推奨値

自然な30fps風:

```text
露光フレーム: 2
サンプリング間隔: 1
重み: 均等
ミックス: 100%
フレーム保持: 2
```

実効60fps素材でStarry系の強めなブラー:

```text
露光フレーム: 3.5～4.5
サンプリング間隔: 1
重み: 線形（古いほど薄い）
線形減衰: 100%
ミックス: 65～80%
フレーム保持: 2
```

59.94fpsファイル内が`A A B B`になる重複30fps素材:

```text
露光フレーム: 3～4
サンプリング間隔: 2
重み: 線形（古いほど薄い）
線形減衰: 75～100%
ミックス: 65～75%
フレーム保持: 2
```

## v0.2.0の変更点

- サンプリング間隔を1～4Fから選択可能にしました。
- 露光フレームを0.1F単位で調整可能にしました。
- 線形減衰の強さを0～100%で調整可能にしました。
- 新規追加時のミックス初期値を100%から70%へ変更しました。
- v0.1.0で保存した設定との互換性を維持しています。

詳細は `CHANGELOG.md` を参照してください。

## 注意点

- プレビューを途中位置から開始した直後は履歴がないため、数フレームかけて本来の濃さになります。
- タイムラインを逆方向へ移動した場合は、誤った残像を防ぐため履歴をリセットします。
- 映像内の動きは積算されますが、この初版ではYMM4側の位置・拡大率・3D回転アニメーション自体の軌跡までは積算しません。
- 設定に応じて最大29枚のフル解像度フレームをGPUメモリに保持します。高いサンプリング間隔と長い露光を同時に使うとVRAM使用量が増えるため、4K素材では控えめにしてください。
- 実験版です。重要なプロジェクトはバックアップしたうえで使用してください。

## ソースからビルド

Visual Studio 2026または.NET 10 SDKが必要です。

```powershell
dotnet build .\src\YMM4ShutterBlur\YMM4ShutterBlur.csproj `
  -c Release `
  -p:YMM4DirPath="C:\Path\To\YukkuriMovieMaker4"
```
